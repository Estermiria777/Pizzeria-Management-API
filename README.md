# Pizzeria-Management-API
A robust RESTful API built with Python, FastAPI, PostgreSQL, and SQLAlchemy to manage pizza orders, customers, menu items, flavors, and real-time ordering logic

A high-performance RESTful API designed to power a modern pizzeria management system. This application streamlines the end-to-end ordering workflow — handling customer accounts, menu items, customizable pizza flavors, order quantities, and live status tracking.

---

## ✨ Key Features

- 👤 **Customer Management:** Full CRUD operations for customer registration and account details.
- 🍕 **Menu & Flavors Catalog:** Manage available pizza flavors, toppings, sizes, and pricing.
- 📦 **Order Processing:** Create, update, and track customer orders with multiple items and quantity controls.
- 🗄️ **Database Migrations:** Managed schema updates powered by Alembic.
- 📄 **Interactive API Docs:** Automatic Swagger UI and ReDoc documentation provided by FastAPI.

---

## 🛠️ Tech Stack

- **Language:** Python 3+
- **Framework:** [FastAPI](https://fastapi.tiangolo.com/)
- **Database:** [PostgreSQL](https://www.postgresql.org/)
- **ORM:** [SQLAlchemy 2.0](https://www.sqlalchemy.org/)
- **Database Migrations:** [Alembic](https://alembic.sqlalchemy.org/)
- **Data Validation:** [Pydantic](https://docs.pydantic.dev/)
